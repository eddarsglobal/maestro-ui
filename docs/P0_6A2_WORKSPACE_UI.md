# P0.6A.2 — Governed Workspace UI

- Workspace control is integrated into the chat composer.
- Open Folder and Open File call the authenticated Local Gateway native picker.
- Already-authorized workspaces are listed and can be reactivated.
- The active workspace is sent with the mission as `workspace_id`.
- Mission details show workspace and tool-call count.
- The active workspace is visibly marked READ-only.
- UI translations cover EN, FR, DE, AR, PT, ES, HR and IT.
- Write/Edit/Delete remain disabled until P0.6B.
